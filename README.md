StockFlow 📦

Sistema de controle de entradas, estoque e contas a pagar para pequenos comércios.

🚧 Projeto em desenvolvimento

📌 Sobre o projeto

O StockFlow nasceu a partir de uma necessidade real de um pequeno comércio: organizar o recebimento de notas fiscais, registrar a entrada de produtos no estoque e acompanhar as contas a pagar.

O projeto está sendo desenvolvido como forma de estudo e prática de desenvolvimento de software, aplicando conceitos de programação, banco de dados, APIs e desenvolvimento frontend em uma situação real.

🎯 Objetivo

Centralizar e facilitar o controle das compras realizadas pelo comércio, substituindo parte dos controles manuais por um sistema organizado e de fácil utilização.

O fluxo principal do sistema será:

Nota Fiscal → Conferência → Entrada no Estoque → Contas a Pagar
